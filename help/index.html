    How can we help?¶

    BookReader is an EPUB and PDF reader with an agent that answers with quotes from the book and a review that comes back when it should. This help is organised by task: search above or take the door that looks most like what you are trying to do.

    • Start from scratch

      Install it, add a book, set up the agent and read your first chapter.

      Your first day

    • Read your way

      Table of contents, immersive mode, scroll, columns, themes and warm light.

      Read a book

    • Ask the book

      Select a passage and ask it to explain, cite or find where else the idea appears.

      Ask the book

    • Make it stick

      Turn what matters into cards, review them with FSRS or take them to Anki.

      Turn reading into review

    • Organise the library

      Shelves, smart shelves, reading status and clean metadata.

      Organise your library

    • Offline and on every device

      Install the app, read on a plane, sync with your own Drive and keep a backup.

      Read offline · Sync and back up

    • Bring an agent

      Connect Claude or another agent to your library over MCP, with per-token permissions.

      Connect an AI agent

    • Know what happens to your data

      Where your books live, what the AI sees and what you can export or delete.

      What happens to your data

    If something is off¶

    What is happening Where to start
    The agent does not answer or the demo ran out Set up the agent
    A PDF opens with no table of contents Formats and limits
    I changed device and my books are not there Sync and back up
    I lost a book or a note while syncing Sync and back up
    I do not understand why the agent answered that How the agent answers

    The help, in four quadrants¶

    If you prefer the map:

    • Guides: one task, step by step.
    • Tutorials: one full journey, start to finish.
    • Explanation: the why, no steps.
    • Reference: formats, limits and lookup data.
