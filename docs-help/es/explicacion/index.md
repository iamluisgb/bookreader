# Explicación

Aquí está el porqué, no el cómo. Son páginas para entender qué hace BookReader con tus libros y
tus preguntas, y para saber qué esperar del agente.

- [Qué pasa con tus datos](your-data.md): dónde vive cada cosa y qué sale del dispositivo.
- [Cómo responde el agente](how-the-agent-works.md): qué lee, cómo cita y cuándo se equivoca.

Si lo que buscas es hacer algo, empieza por las [guías](../guias/index.md).
