# Tutoriales

Un tutorial es un recorrido completo, con un principio y un final claros. No explica cada opción:
te lleva de un estado a otro y, de paso, te enseña lo justo para que no te pierdas.

- [Tu primer día](first-day.md): de la instalación a la primera tarjeta, en una sesión.

Cuando ya sepas moverte, las [guías prácticas](../guias/index.md) resuelven tareas sueltas.
