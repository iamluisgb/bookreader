# How can we help?

BookReader is an **EPUB and PDF reader** with an agent that answers with quotes from the book and a
review that comes back when it should. This help is organised by task: search above or take the
door that looks most like what you are trying to do.

## If something is off

| What is happening | Where to start |
| --- | --- |
| The agent does not answer or the demo ran out | [Set up the agent](guias/set-up-ai-key.md) |
| A PDF opens with no table of contents | [Formats and limits](referencia/formats-and-limits.md) |
| I changed device and my books are not there | [Sync and back up](guias/sync-and-backup.md) |
| I lost a book or a note while syncing | [Sync and back up](guias/sync-and-backup.md#if-something-disappears) |
| I do not understand why the agent answered that | [How the agent answers](explicacion/how-the-agent-works.md) |
